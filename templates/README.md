# Free template: Numbered Report

A short report skeleton with outline numbers (1, 1.1, 1.2) and a live table of contents, using only free Section Numbering features.

1. Copy `report-starter/Report.md` into your vault.
2. Turn on **Show numbers** in the plugin settings, or run the number command on the note.
3. Write under each heading. Links to headings keep working when sections move.

Turning notes into a printed book or EPUB? [Book Studio](https://github.com/perezamadorluisenrique-gif/book-studio/tree/main/templates) has a free starter book.
